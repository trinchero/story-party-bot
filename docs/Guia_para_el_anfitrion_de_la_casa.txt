GUÍA PARA PREPARAR LA HISTORIA EN NUMBERS

Abre TEST_BOT_Telegram_2_personajes_historia_independiente.numbers. Edita y guarda con Cmd+S. No necesitas exportar a otro formato.

Conserva los nombres de las hojas y los encabezados. Usa una sola tabla por hoja.

Guia: trama e instrucciones privadas. Nunca se envía a los jugadores.
Personajes: un código único en MAYÚSCULAS, nombre, descripción y ficha privada por personaje.
Fases: numera desde 1, sin saltos. Añade título y notas para ti.
Mensajes: una fila por mensaje. Fase indica cuándo se usa; Orden empieza en 1 dentro de cada fase. Destinatarios: TODOS, un código o varios códigos separados por comas. Título admin y Notas admin son para ti. Texto es lo que se enviará.

La fase 1 puede tener un solo mensaje de bienvenida para TODOS. Desde la fase 2 puedes combinar mensajes privados y colectivos en el orden deseado. Si eliminas un mensaje, vuelve a numerar Orden sin huecos.

No uses fórmulas ni celdas combinadas en las tablas de datos. Guarda como archivo Numbers único, sin contraseña. Entrega ese mismo archivo al responsable técnico para importarlo.

EN LA DASHBOARD
Asignaciones: asigna o libera personajes. Cuando estén todos, confirma para bloquearlos.
Partida: Iniciar partida muestra una vista previa y, al confirmar, envía el primer mensaje de la fase 1.
Mensajes: consulta el avance por fase y abre cada mensaje para ver las entregas.
Terminar partida pide confirmación y conserva el historial.

Las fichas de Personajes no se envían automáticamente con el flujo web. Incluye los textos privados que quieras enviar como filas de Mensajes en la fase correspondiente. Las notas y la guía siempre son privadas.
